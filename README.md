# Patitas Felices

Tienda online ficticia de productos para perros y gatos, pensada para funcionar con dropshipping (sin stock propio).

## Páginas
- `index.html` — Inicio
- `productos.html` — Catálogo (4 productos)
- `detalle.html` — Detalle de la fuente de agua para gatos, arnes, comedero y peluche
- `contacto.html` — Contacto con formulario

## Cómo abrirlo
Abre `index.html` en el navegador con doble clic. No necesita servidor.

## Tecnologías
HTML5 semántico y CSS externo (mobile-first con media query). Sin JavaScript.
